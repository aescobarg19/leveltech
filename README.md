# leveltech
un programa educativo que impulsa a jóvenes a explorar la tecnología mediante programación, electrónica y creatividad. A través de experiencias prácticas, desarrolla habilidades digitales, pensamiento lógico, innovación y confianza para crear soluciones tecnológicas.

Problema que resuelve: La falta de oportunidades de formación tecnológica práctica y acceso a conocimientos digitales en jóvenes.

¿A quién le sirve?: A jóvenes de 14 a 18 años interesados en la tecnología, la programación y la innovación.

Estado actual: Proyecto educativo desarrollado en Rincón ClubHouse Explora, con talleres prácticos de programación, electrónica, HTML, Python y Arduino.
